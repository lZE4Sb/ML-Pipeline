**** ML-Pipeline

Пайплайн для запуска оптимизации гиперпараметров и/или обучения Бустинг(XGBoost, LightGBM,CatBoost) и Torch моделей. 

На данный момент доступны 3 типа задач: регрессия, бинарная и мультиклассовая классификация. 

**Валидация:** на данный момент настроена кросс-валидация по фолдам.

Необходимая настройка для работы: 
1) подготовка данных в data.py:
	1) Функция `stateless_preprocessing` (Изменения внутри строк)
	2) Заполнение глобальных переменных колонками по типу изменения
	3) Редактирование пайплайна препроцессинга sklearn (функция `make_pipeline`)
2) Редактирование конфига:
	1) **Выбор режима запуска в result** 
	   Для запуска оптимизации Optuna: result - mode - study - _true_ 
	   Для запуска обучения модели по параметрам из конфига/полученным из Optuna: result - mode - train - _true_
	2) **Data:** 
	   **pipeline**: выбор пайплайна sklearn для подготовки данных (_linear_ для torch и прочих моделей/_boosting_ для бустингов). 
	   **log_transform_target**: логарифмирование таргета (для регрессии)
	3) **Model choosing:** Выбор модели для оптимизации и обучения.
	4) **Optuna:** 
	   **n_trials**: количество запусков. 
	   **metric**: оптимизируемая метрика (можно редактировать список в metrics.py). **num_iterations_strategy**: выбор количества эпох/деревьев для финальной модели при кросс-валидации.

### Как использовать

1. `pip install -r requirements.txt`
2. `python -m main` для запуска подбора Optuna и/или обучения модели нейросети/бустинга.
